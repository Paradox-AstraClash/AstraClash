# AstraClash
AstraClash is arcade space combat in a live asteroid field. Mine blue ore for XP and Ore Mana, climb a 5-tier upgrade tree, and fight up to five pilots at once. Track enemies with off-screen markers, outmaneuver them in the void, and top the kill board. Check it out at [astraclash-five.vercel.app](https://astraclash-five.vercel.app)!
